# elyotam.github.io

Personal site — served at <https://elyotam.github.io>.

Plain HTML, CSS and JavaScript in a single `index.html`: no framework, no build
step, nothing to install. Editing the file and pushing is the whole deploy.

- `assets/icons/` — tech-stack tiles, shared with the profile README
- `assets/work/` — screenshots of the live sites in the work section

The GitHub numbers in the "On GitHub" section are fetched from the public API
when the page loads, so they never need regenerating.
